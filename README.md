# Swampurna 🌿
**Empowering through Knowledge & Hygiene**

## Project Overview
Swampurna is a digital initiative created to provide accurate, respectful, and accessible information regarding menstrual health. The platform aims to educate young girls on essential hygiene practices through a user-friendly interface.

## 👨‍💻 Creator
**Paras Jha** *Assisting Programmer | Percussionist | Fitness Enthusiast*

## 🎨 Design Philosophy
The website features a **Reddish-Brown (Terracotta)** theme, chosen to represent a grounded, natural, and authentic aesthetic. The focus is on readability and ease of navigation.

## 🛠️ Technical Stack
- **HTML5:** Semantic structure for health information.
- **CSS3:** Custom Earth-tone styling and responsive layouts.
- **JavaScript:** Logic for the interactive MCQ assessment.

## 💡 How to Use
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Explore the Hygiene Tips and test your knowledge with the built-in Quiz.
